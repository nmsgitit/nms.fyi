# nms.fyi

An interactive 3D site: a scripted walk into a 1980s retro-futurist command room
overlooking a server room, leading to a mock retro operating system.

```bash
npm install
npm run dev     # development server at http://127.0.0.1:5173
npm run build   # production build into dist/
npm start       # serve dist/ (PORT env var, default 3000)
```

Built with Three.js, Vite, and Express. See `CLAUDE.md` for architecture and status.
